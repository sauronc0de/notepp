# **Notes App**

This application is written in **C++** and uses **Dear ImGui** for the user interface.  
It allows users to **store, view, and manage notes** in a lightweight and responsive desktop application.

Notes are written in **Markdown format**, making them easy to read, edit, and track with version control systems.
